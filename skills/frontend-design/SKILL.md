# Frontend Design

## Trigger
ใช้เมื่อสร้างหรือปรับหน้าเว็บ component หรือ visual system

## Principles
- เลือก palette, typography และ layout ให้เหมาะกับเนื้อหา ไม่ใช้ template เดิมซ้ำโดยไม่คิด
- ให้ hero/primary action สื่อหน้าที่ของหน้าได้ทันที
- ใช้ข้อความที่ชัดเจนและเรียก action ตามผลลัพธ์จริง
- รองรับ mobile, keyboard focus, contrast และ reduced motion
- ใช้ motion เท่าที่ช่วยอธิบายการเปลี่ยนแปลง

## Review
ก่อนส่งมอบ ตรวจ responsive layout, overflow, loading/empty/error states และ console errors
